## Wordmark presentation variants

Lettering-only variants are available for other page compositions. Original
lockups remain available as `logo.svg` / `logo.png`. The separate `wordmark`
assets for ByteDance, Replit, Freshworks, Toss, and CyberAgent isolate the existing
lettering from those sourced lockups, without redrawing or changing letter paths.
SVG symbol paths are omitted and the viewBox trimmed; PNG variants crop the
separate symbol and transparent margins. These are prepared presentation variants,
not separately downloaded or certified brand-kit variants.

## Alternative symbol assets (not used on the homepage)

The alternative Figma asset is the official pack's full-color lockup (`lockup.svg`), with only
transparent surrounding whitespace removed. If used, it should retain the approved icon colors. Polestar's symbol comes from
its current [official touch icon](https://www.polestar.com/w3-assets/apple-touch-icon.png);
the dark square background is made transparent and surrounding whitespace trimmed.
The homepage pairs the current Polestar symbol with its wordmark as separate
assets. This is a page composition, not a downloaded official combined lockup.
Other alternate symbol assets are retained for future review.
Zomato's square mark contains its wordmark; its current identity does not have
a separate standalone pictorial symbol.

## Figma outline symbol

`symbol-outline.svg` is the official “Figma Icon (Mono-line black)” from the
[download pack](https://static.figma.com/uploads/4fbf4d754dbbc027ba1530205f8747cd97d532e5).
Only the surrounding transparent canvas was cropped; the outlined paths are
unchanged. The homepage places this beside the existing wordmark as two separate assets;
the wordmark carries alt text “Figma”.
The [brand book](https://static.figma.com/uploads/6645755656177435f83e10b48d9947645b55a033)
provides the mono-line icon and prohibits creating custom logo combinations,
so this page composition is not represented as an officially supplied lockup.
It uses the requested outlined icon rather than the rounded app icon.

Raster assets added during the WWW renewal (Freshworks, Toss, and the Polestar symbol) are deployed as lossless WebP. Freshworks/Toss lockups and wordmarks are capped at 600 × 200 pixels for website use; the Polestar symbol retains its original dimensions. SVG geometry is unchanged.
