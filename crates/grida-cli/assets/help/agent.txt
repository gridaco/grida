Grida Agent — headless tasks and ACP

Commands:
  run           Run one prompt through Grida Gateway and print JSON Lines
  run-external  Run one prompt through a reviewed local ACP peer
  serve         Serve an Agent Client Protocol client over stdio

For run and serve, select --provider gg and a Gateway chat model explicitly.
These commands use your existing Grida login and the selected organization's Gateway capacity.
Use --org or --org-id when your account has multiple organizations.

Documentation: https://grida.co/docs/cli/agent
