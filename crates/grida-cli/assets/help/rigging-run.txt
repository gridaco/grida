Usage: grida rigging run --provider tripo|gg --model <id> --out <new-directory> (--mesh FILE --rig-type <type> --spec tripo|mixamo | --input @file|-) [--key-stdin] [--json]

Explicitly submit a paid rigging operation and save its GLB and task receipt.
Run rigging check first to inspect eligibility; check and run are separate commands.
Run rigging inspect for the model's supported rig types and specification.
Local GLBs: at most 60,000,000 bytes; JSON input: at most 16 MiB.
JSON mode cannot mix with mesh, rig-type or spec flags.
--out must be a new directory under an existing parent. No files are overwritten.
BYOK key precedence: stdin, TRIPO_API_KEY, shared credentials.toml.
GG uses Grida login and --org or --org-id; --key-stdin is BYOK only.
No automatic retry. An interrupted request may still be charged.

--no-input suppresses terminal interaction; the OS keyring may still request access.
Documentation: https://grida.co/docs/cli/generate
