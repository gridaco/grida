Usage: grida auth logout [--json] [--no-input]

Remove this CLI's credentials and request revocation of this CLI session only.
Other sessions and provider API keys are left intact.
Unconfirmed remote revocation exits 1; an already signed-out profile exits 0.

--no-input suppresses terminal interaction; the OS keyring may still request access.
Documentation: https://grida.co/docs/cli/auth
