Grida — account access and tools

Usage: grida <command>

Commands:
  auth       Sign in and manage this CLI's session
  account    Read your identity, organizations and credits
  ai         Manage provider keys, discover models and generate media
  docs       Print canonical documentation URLs

Options: --help, --version
Use grida <command> --help for details.

--no-input suppresses terminal interaction; the OS keyring may still request access.
Documentation: https://grida.co/docs/cli
