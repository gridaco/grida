# Grida

<!-- GRIDA-SEC-010 / GRIDA-SEC-013 / GRIDA-SEC-014: contributor contracts live at https://github.com/gridaco/grida/blob/main/packages/grida-cli/CONTRIBUTING.md. -->

Generate images, video, audio and 3D assets from your terminal.

Discover AI models, bring your own API keys or use Grida credits, and save the
results directly to your projects.

## Get started

Requires Node.js 24 or later.

```sh
npm install -g grida
grida --help
```

[Read the docs](https://grida.co/docs/cli) for setup, supported platforms,
provider configuration and examples.
