# Models & Pricing

Browse [Grida's current model catalogue](https://grida.co/ai/models) for supported
Gateway models, capabilities and usage prices. The page reads Gateway discovery;
this guide does not maintain a separate list or rate card.

Grida-hosted AI spends your organization's prepaid AI credits. API and product
usage share that balance. [Manage credits and automatic top-ups in
Console](https://console.grida.co/_/billing). Connected provider keys use your
own provider account and its terms and prices.

## Product choices

Agent tiers (`nano`, `mini`, `pro`, `max`) are Grida product presets for background
work through demanding tasks. They select models; they are not separate model
families or a promise of a particular provider. Desktop also offers an explicit
model/provider choice. ChatGPT subscription, connected keys and custom endpoints
remain separate authentication and billing paths.

An installed client offers the interfaces its adapters implement. New Gateway
models using those interfaces can appear without a client release. A new modality,
transport or result format may require an update. A saved model choice is not
silently changed to another model when availability changes.

Background removal and upscaling are dedicated product tools. Internal Library
embeddings use a persisted model and vector format. Neither is an additional
public Gateway catalogue.

For API integration, start with [Gateway's integration contract](https://gateway.grida.ai/llms.txt).
